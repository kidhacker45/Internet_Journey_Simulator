    EVENT LOG

      Realism notes

      • REAL CONCEPT vs SIMPLIFIED SIMULATION: real Internet routes are dynamic; the fixed router chain shown here is a teaching model, not a traceroute.
      • Modern browsers often use HTTP/3 + QUIC (UDP) instead of TCP. This simulator shows the classic TCP + TLS 1.3 path because it is easier to reason about.
      • Real pages trigger many more DNS lookups, connections and sub-resource requests. This shows one simplified request/response.
      • MAC addresses are link-local and change at every routed hop; IP routing is not a fixed physical map. BGP exchanges reachability between autonomous systems — it does not pin every packet to an exact route.
      • NAT behavior varies between routers and carriers. Mobile networks frequently use carrier-grade NAT, so a phone may never hold a public IPv4 address.
      • All addresses, AS numbers, routers and Google infrastructure shown are illustrative. This simulator models common networking concepts — real paths, DNS answers, NAT behavior and cloud infrastructure vary.
